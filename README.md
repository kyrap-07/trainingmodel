# 🤖 Image Classification using Teachable Machine

A beginner-friendly **Machine Learning image classification project** created using **Google Teachable Machine**.

Live demo : https://teachablemachine.withgoogle.com/models/cvhm0Syfz/

## 📌 About the Project

This project explores the basic workflow of training an image classification model using sample images.

The model was trained to recognize different categories based on the image examples provided during training.

It was created as a hands-on introduction to fundamental Machine Learning concepts such as:

* Data collection
* Image classification
* Training data
* Model training
* Testing and prediction
* Generalization

## 🛠️ Tool Used

* **Google Teachable Machine**
* Image Classification

## 🔄 Machine Learning Workflow

```text
Collect Image Samples
        ↓
Organize into Classes
        ↓
Train the Model
        ↓
Test with New Images
        ↓
Generate Predictions
```
